# A365 Capability Explorer

**Map any agent use case to Microsoft Agent 365.**

Live site: <https://chriswillia.github.io/a365-capability-explorer/>

> Independent project, not an official Microsoft site. Microsoft product names are trademarks of the Microsoft group of companies.

A365 Capability Explorer helps people who design, build and govern AI agents answer six questions within ten minutes: what Microsoft Agent 365 offers today, which capabilities apply to a given agent and why, where each one acts, who owns it and when it matters, what is already in place, and what would change the answer.

## How to use

Read the overview, then browse the capabilities. Search includes discovery questions and synonyms in the catalog's tags. Choose a pillar, console, layer, lifecycle, risk or pattern lens; switch views; and select up to four capabilities to compare. Explorer settings are kept in the URL, so bookmarks and browser history preserve them. Open a capability for its brief, sources, scope rules, typical patterns and correction link.

Explore Patterns for read-only illustrative results using visible canonical answers and a neutral organization. Matrix cells are generated by the same engine as pattern briefs. Each recommendation keeps its reasons and evidence; missing answers remain unknown. Technical adds operating-model and anatomy tables, control intensity and illustrative what-if deltas. Methodology exposes the rules, risk associations and unsigned golden scenarios. These pages save no assessment data and do not certify readiness, eligibility or license quantities.

Open Diagnostic to create a reusable organization profile, then start a Quick scan or Full diagnostic from blank, a pattern or a sample. Pattern starters preserve your selected organization context rather than copying neutral assumptions. Answers, mode and section autosave locally; resume, duplicate, rename and delete assessments from the diagnostic home. Switching modes preserves answers. The wizard includes consultant notes, an emerging anatomy with a table alternative and a clearly labeled live planning preview, not a formal readout.

Choose **Open readout** from a saved assessment or its review step. Results are recomputed with current content and marked **Draft for discussion**; older or incompatible answers are never silently corrected. Executive shows the six decision-oriented exhibits; Technical shows all eleven and the appendix, including what-if comparisons that do not alter saved answers. Use **Print / save PDF**, **Download Markdown**, **Download assessment JSON**, **Download PowerPoint**, or **Copy executive summary**. PowerPoint contains exactly six editable slides; complete detail and any shortened text are in speaker notes. Markdown always exports the full technical readout.

Optional co-branding accepts a local PNG or JPEG up to 2 MiB and 4096 pixels per side, with a required description. The image is normalized to a bounded PNG, stored with the assessment and preserved in copied/imported assessments. JSON, PDF and PowerPoint include the logo; nothing is uploaded. Open the eleven-box Use Case Canvas for a workshop handout or a one-slide PowerPoint export, or use the blank canvas without creating an assessment. Success measures and the accountable owner are editable in the Full diagnostic. Print the canvas in landscape. Filled canvases are one-page summaries with explicitly marked shortening; complete answers remain in the readout and Markdown export.

Download a workspace JSON backup from Diagnostic to include every organization and assessment. To restore or transfer work, choose an exported JSON file (up to 5 MiB), review its counts, then confirm **Import as new copies**. Imports always assign new ids and preserve relationships, original answer values and original content versions. They never overwrite existing organizations or assessments, even when names or ids match. Review save-status messages after importing; a storage failure leaves the imported copies in memory until saving succeeds.

Open **Portfolio** to compare saved assessments for one organization. Select which cases to include; results always use current content without changing saved answers. Business value at least 3 and control intensity at least 50% are explicitly labeled draft planning cutoffs, not investment recommendations. Bubble areas represent ordered expected-user bands, not headcounts; unknown business values are listed but not plotted. The comparison table gives every chart value. Shared foundations only count platform/both capabilities used by multiple selected cases in that organization; agent decisions still apply. Readiness keeps gaps and unknowns separate. Licensing counts deduplicate capabilities, never users or license quantities. Incompatible answers are visibly excluded from calculations and can still be exported for recovery.

**Download selected portfolio JSON** includes only selected assessments and their organization. Import uses the same preview/confirmation and new-copy behavior as Diagnostic. JSON exports above the 5 MiB import limit are blocked with an explicit message; select fewer assessments. Selection, organization filters and presentation mode are temporary, not new browser-storage records.

Open **Workshop** for a data-driven 90-minute facilitator guide, paired front/back pattern cards, capability card-sort materials and a link to the blank canvas. Print the guide or either card set separately on A4 or Letter. Card sides are paired on the same sheet for cutting/folding, not printer-dependent duplex alignment. Card summaries, scope conditions, draft labels and evidence come from the existing catalog and rules. **Enter presentation mode** on Workshop, Portfolio, Readout or Canvas to increase type size and hide editing controls; the exit button or Escape restores the normal view. Nothing is saved by entering presentation mode.

## Run it locally

For a guided starting point, select your role on the overview. The Learn hub separates related building blocks from catalog capabilities, links source-backed explanations to official documentation, and offers a complete table alongside the step-through concept guide. Switch to Technical for integration details. Glossary links in explanatory prose lead to definitions; focus or hover reveals a definition tooltip, and Escape dismisses it. Pending licensing answers are not licensing guidance.

Requires Node 24 (see `.nvmrc`).

```bash
npm ci
npm run lockfile:check # public npm URLs, also checked before CI installs
npm run dev          # http://localhost:5173
npm test             # unit and component tests
npm run test:e2e     # builds for both base paths, then runs Playwright and axe
```

## How to contribute

Content is data: capabilities, sources and all interface copy are YAML files in `content/`, so you can fix or add content without touching code. See [how to update content](docs/HOW-TO-UPDATE.md). For code, see the [architecture notes](docs/ARCHITECTURE.md). Use the issue tracker for corrections and ideas.

## Hosting

The site is a public GitHub Pages project site, built and deployed by GitHub Actions on every push to `main`. A published change can take up to about ten minutes to appear.

Visibility: public from the first deploy, with a `noindex` tag until launch. A privately published Pages site needs an organization on GitHub Enterprise Cloud, and an enterprise that uses Enterprise Managed Users can only publish privately. See GitHub's documentation on [changing the visibility of a Pages site](https://docs.github.com/pages/getting-started-with-github-pages/changing-the-visibility-of-your-github-pages-site).

## Privacy

Everything runs in your browser, with no cookies or analytics. Catalog searches, filters and comparison selections appear in the URL. Loading or sharing that URL exposes its query string to the host or recipient, so do not enter confidential information in catalog search. GitHub Pages logs visitor IP addresses for security purposes. See the Privacy page on the site.

Diagnostic answers, names and optional normalized logos stay in this browser profile, not URLs or network requests. They are accessible to anyone sharing that profile and disappear if site data is cleared. Storage failures retain edits in memory with visible warnings; do not close the page before saving succeeds. Conflicting tabs never intentionally overwrite a newer saved workspace. Corrupt or unsupported data is preserved for recovery until an explicit reset. JSON, Markdown, PDF, PowerPoint and copied summaries contain your answers and optional names; JSON, PDF and PowerPoint also include any selected logo. Review exports before sharing; they are not encrypted by this app. Import reads a selected file locally; nothing is uploaded.
